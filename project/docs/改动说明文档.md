# 第二轮迭代(2026-07-14)

## 五、问题修复(BUG)

### 13. 智能体配置弹窗被挤压在侧栏内(用户截图 1)
- **文件**:`src/views/newBI/aiBodyPage/index.vue`
- **根因**:el-dialog 渲染在窄的智能体侧栏(flex 子容器)内部,弹窗被父容器宽度约束挤压变形,无法操作
- **修复**:为 el-dialog 增加 `append-to-body`(挂载到 body,脱离侧栏布局),并设定 `width="880px" top="8vh" :close-on-click-modal="false"`,统一使用 `my-custom-style` 弹窗样式
- 已验证:点击 + 新建/编辑智能体,弹窗居中全屏遮罩正常展示

### 14. 数据源弹窗 JDBC URL 显示 `undefined:undefined/`
- **文件**:`src/views/dataSourceManager/newDataSourcePage/index.vue`
- `JDBCSplice` 计算属性对未初始化字段直接拼接导致 undefined 字样;改为空值兜底(`host/port/defaultDb || ""`)

### 15. newAiBodyPage 缺失 `deleteMetric` 方法(潜在运行时报错)
- 模板中知识行删除按钮引用了 `deleteMetric(row)` 但方法从未实现,点击必报错
- 已补齐实现:从 `tableRelations[i].relations` 移除该行、清理空分组、并通过 `toggleRowSelection` 同步取消左侧表格勾选
